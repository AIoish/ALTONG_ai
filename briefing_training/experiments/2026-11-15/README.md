# 1.7B 브리핑 모델 비교 기록

2026-11-16 기준 실험 기록이다. 기존 인계 문서의 2026-11-06 결과 이후 진행한 추가 학습과 평가를 구분한다. 이 폴더의 대화는 가상 합성 사례이며 실제 알림을 수집한 자료가 아니다.

## 모델과 학습

- 기존 모델: `Qwen/Qwen3-1.7B` + v9 어댑터를 초기값으로 보강 36건, 이어서 보강 30건을 순차 학습한 어댑터 (`v9-plus36-plus30-pilot`).
- 현재 모델: 같은 v9 어댑터에 카톡형 50건, 보강 36건, 보강 30건을 순차 학습한 어댑터 (`chat50-plus36-plus30-pilot`). 50건은 10개 템플릿의 변형이므로 서로 독립적인 50개 상황으로 보지 않는다.
- 36건과 30건은 AI가 작성한 합성 대화이며 사용자가 기대 요약 초안을 검토했다. 해당 건수를 v9와 단순 합산해 한 번에 학습한 것으로 해석하지 않는다. 데이터 구성과 한계는 [데이터셋 점검](../../DATASET_AUDIT_AND_PLAN.md)을 함께 참고한다.
- 학습 데이터 30건과 데이터 설명: [Hugging Face 데이터셋](https://huggingface.co/datasets/MiinJuun/altong-briefing-v9-chat50-private/tree/main/data/chat30-error-repair). 모델 가중치와 어댑터는 이 PR에 포함하지 않는다.

## 25건 비교

[평가 입력 및 기대 요약](evaluation25-reviewed.jsonl)은 학습에 넣지 않은 가상 사례이며 사람이 기대 요약을 검토했다. 정확히 동일한 입력 중복을 확인한 결과와 의미적으로 유사한 사례가 없다는 주장은 다르다. 이 25건은 반복 검토와 프롬프트 개선에 사용했으므로 최종 미노출 시험셋으로 취급하지 않는다.

두 모델의 원래 프롬프트와 현재 모델의 수정 프롬프트를 각각 같은 입력으로 비교했다. Python Transformers, greedy 생성, 카테고리 자동 교정 비활성화 조건이다. GGUF 추론 결과가 아니다.

| 조건 | 결과 | JSON 계약 준수 | 사례 통과율 |
|---|---|---:|---:|
| 기존 모델 + 기존 프롬프트 | [25건 입출력](v9-plus36-plus30-review.md) | 24/25 | 12/25 |
| 현재 모델 + 기존 프롬프트 | [25건 입출력](chat50-plus36-plus30-review.md) | 25/25 | 13/25 |
| 현재 모델 + 수정 프롬프트 | [25건 입출력](chat50-plus36-plus30-prompt-review.md) | 25/25 | 14/25 |

이 사례의 자동 평가에는 핵심 사실·금지 표현 조건이 설정되지 않아 `0/0`이다. 사례 통과율은 사실관계와 요약 품질의 정답률이 아니며, 주로 카테고리 일치 등 형식 조건을 반영한다. 세 숫자만으로 요약 품질의 향상을 주장할 수 없다. 원문·기대 요약·모델 출력을 함께 검토해야 한다.

수정 프롬프트에서는 13번의 교수 확인 전 외부 배포 보류가 반영됐다. 반면 1번은 연장된 전시관을 연장할 수 없다고 하고, 15번은 동명이인 신청을 중복 신청으로 표현한다. 20번은 없는 작업 완료를 추가하며 21번은 분할 전송을 검토하는 단계에서 실행 예정으로 단정한다. 잡담 8·25번의 문장과 맥락도 부자연스럽다. 개인 식별·업무 담당자, 부정 및 미확정 상태, 누락과 환각을 계속 확인해야 한다.

## 프롬프트와 GGUF

[수정 시스템 프롬프트](experimental-system-prompt.txt)는 위 실험에서만 사용했다. 줄바꿈을 LF로 정규화한 UTF-8 텍스트의 SHA-256은 `e60e0081cbf2ae1a59c72eeb0495de089c1e3cd003beaf146ac62344abdfafd3`이며, 앱 또는 기본 평가 프롬프트는 이 실험 때문에 변경되지 않았다. GGUF에는 시스템 프롬프트가 자동 적용되지 않는다. 동일한 사용자 입력 형식, Qwen3 비사고 모드, 생성 설정과 함께 호출 측에서 제공해야 한다.

현재 모델을 병합해 Q8_0 GGUF 파일을 생성했으며, 파일 구조에서 Qwen3와 텐서 310개를 확인했다. 변환된 GGUF의 요약 추론 및 변환 전 모델과의 출력 동등성, 성능·속도·메모리와 클라이언트 연동은 아직 확인하지 않았다. 기존 병합 스크립트가 생성하는 프롬프트 예시는 수정 실험 프롬프트가 아니다.
