보고서는 `outputs/v8-q8-category.json`, `outputs/v8-q8-category-review.md`입니다.

짧은 요청 8건 Q8 결과: JSON·분류 8/8, 필수 사실 포함 100%, 전체 조건 7/8 (87.5%),
평균 7.83초. 기존 HF는 전체 조건 8/8이었습니다. Q8의 보안 완료 사례는 핵심 사실을
모두 포함했지만 1줄 기대 조건을 넘겨 2줄로 출력했습니다. 이 차이를 숨기는 줄 합치기 보정은 하지 않았습니다.
보고서는 `outputs/v8-q8-short.json`, `outputs/v8-q8-short-review.md`입니다.

같은 원문·프롬프트·토큰 ID를 확인한 후 비사고 모드, greedy, 최대 256토큰으로 생성했습니다.
JSON 강제 문법, 요약 보정, 정답 전달은 사용하지 않았습니다.
모델 병합·런타임·양자화가 달라져 품질 차이의 원인을 양자화 하나로 단정할 수 없습니다.

원문 기반 분류 교정은 별도 Python 코드입니다. GGUF만 실행하면 표의 **원본 분류**입니다.
8건은 알려진 실패 유형을 보강한 소규모 합성 사례이며 실사용 일반 정확도가 아닙니다.

## 남은 품질 한계

- "제 로그인이 아니에요"를 로그인 실패로 바꾸는 의미 왜곡.
- 응답 표, 중간 점검, 실험 순서 확인 등의 정보 누락.
- 배송 사례의 "무인 택배함에 뒤집었습니다"는 자동 평가에 통과해도 부자연스러운 요약.
- 기본 평가에는 한국어 요청에 영어로 답하는 예약 사례, 야간을 주간으로 바꾸는 사례도 남아 있습니다.

따라서 사람이 결과를 확인하는 통합 MVP 후보이지 완성 모델이나 무검토 자동 등록용 모델이 아닙니다.
